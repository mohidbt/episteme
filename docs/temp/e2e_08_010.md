## Known quirks (don't flag as bugs)

- `PublishDialog` URL preview always shows `.epistaime.com`, not `.epistaime.local:3001`. Intentional (client constant, no env leak to browser). Copy button copies the prod URL.
- Next.js ISR cache (`revalidate: 60`) on `/pub/*` means unpublish may briefly still resolve in production; dev is usually cache-bypassed but not guaranteed.
- `pre-ai-edit` revisions appear in the drawer but have no "revert" affordance — intentional; use the normal restore flow.
- `INHALE_STUB_EMBEDDINGS=1` makes RAG tests useless (stub vectors return random-ish ranking). Must be `0` for 2.7–2.9 semantic tests.
- Autosave debounce is 800ms. Always wait ≥1.5s after the last keystroke before asserting DB state.
